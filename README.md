## Scope and status

This submission describes a **proposed** open-source Canton/Daml reference infrastructure, including tax-lot interoperability, Proof-of-Basis evidence, proxy voting and voluntary corporate-action election workflows. Proposed integrations, pilots, audits and capabilities are not represented as completed. The open-source reference layer is intended to operate independently of proprietary Netbasis algorithms, datasets and licensing. The proposed Apache-2.0 licensing approach remains subject to legal review.

**Publishing note:** Review the content for confidentiality, security disclosures and grant-submission permissions before making the repository public. The Markdown documents are formatted for GitHub rendering; their content follows the supplied final documents rather than introducing new implementation claims.
